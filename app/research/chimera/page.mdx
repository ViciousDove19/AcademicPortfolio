# CHIMERA

<Stamp>MICCAI 2026 Challenge submission</Stamp>

*Policy-orchestrated specialist agents for prostate-cancer decision support.*

## In plain language

Start with the problem a clinician actually has: a prostate-cancer guideline
isn't one rule, it's a pathway — the same finding means something different
depending on where a patient already is in that pathway, and evidence can be
missing or conflicting. A single model that reads everything and outputs a
decision has to hold all of that context implicitly, which makes it very
hard to check *why* it decided what it decided.

So this project doesn't build one model. It builds a graph. The guideline
itself — the EAU prostate-cancer pathway — becomes an explicit map of
narrow questions. A small "specialist" agent answers each question using
only the evidence relevant to it, and hands back a structured verdict. An
orchestrator, not the specialist, decides which edge of the graph to follow
next. Walk that process to the end and you get a decision *and* a full
record of how it was reached — which pieces of evidence were used, how
confident each step was, and a written rationale that's checked against the
evidence before anyone sees it.

## Overview

Prostate-cancer decisions combine imaging, biomarkers, and pathology, but
what each finding means depends on the patient's current point in the
clinical pathway. End-to-end models have to infer that context implicitly
while interpreting evidence, which makes it hard to verify whether any
single variable was actually applied correctly. CHIMERA asks whether making
that structure explicit — instead of asking one model to hold it all in its
head — produces decisions that are both accurate and auditable.

## Method

The EAU prostate-cancer guideline pathway is encoded as an explicit,
executable policy graph. Every node in the graph is one narrow clinical
question. Where the answer is a structured value, it's read directly; where
it depends on narrative text, a specialist agent — radiology, biochemistry,
and so on — reads only the evidence relevant to that node and returns a
structured verdict: its call, the findings that support it, which variables
it used, and a short local rationale. The specialist's verdict selects which
edge of the graph to follow; the orchestrator walks the graph, not the
specialists. When evidence is missing, the graph has an explicit fallback —
retrieve it, order the prerequisite test first, or follow a dedicated
historical branch.

Once a full path is traversed, that trace drives three things: a weight for
every clinical variable involved (from *not used* to *decisive*, based on
where in the graph it mattered and whether it actually changed the
decision), a confidence level (*clear*, *borderline*, or *uncertain*,
evaluated in a fixed order so a weak downstream signal can never override a
stronger upstream one), and finally a written rationale — produced by a
separate rationale writer that cannot alter the decision, the weights, or
the confidence, and which is checked by a validator against the evidence
actually revealed before it's shown.

## Data

Evaluated on all 163 labelled cases from the CHIMERA-Agent challenge — 91
biopsy-decision cases and 72 management-decision cases — via the official,
live MCP evaluation interface.

## Status & links

Submitted to the CHIMERA-Agent Challenge at MICCAI 2026. Code is available
at [github.com/ViciousDove19/chimera-baseline](https://github.com/ViciousDove19/chimera-baseline),
explicitly marked as not for clinical use without external validation.
The specialists currently hold task-focused rather than comprehensive
clinical knowledge — sharpening that is the identified next step.
