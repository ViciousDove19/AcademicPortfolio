## In plain language

Segmentation papers almost always assume the same shape: an encoder that
understands the image, and a decoder that turns that understanding back
into a pixel-by-pixel mask. The decoder is usually taken for granted — of
course you need one, how else would you get back to pixel resolution?

This project pokes at that assumption directly. Instead of a decoder, it
uses a single linear layer on top of the Vision Transformer's own patch
tokens — one number per patch, trained to predict what *fraction* of that
patch is tumour, not just whether it is or isn't. At inference, that's a
sigmoid, a reshape into a grid, and a bilinear upsample. No decoder at all.
An oracle experiment backs this up: if you compute the best-possible
continuous per-patch label directly from the ground-truth mask and just
upsample *that*, you already recover almost all of the achievable
segmentation quality — which suggests the usual "token classification is
too coarse" objection is really about label softness and patch size, not
about needing a decoder.

## Overview

Encoder-decoder segmentation adds real parameter count and training
overhead on top of the encoder alone — a cost point-of-care deployment
feels acutely. This project asks whether that decoder is actually earning
its place, or whether a much smaller mechanism can do nearly as well once
patch size and label softness are handled properly.

## Method

The segmenter is a ViT encoder plus a linear head — 194 parameters at
ViT-Tiny scale — producing one logit per patch token, trained with
binary cross-entropy against the *continuous* tumour-area fraction inside
that patch, not a binarised label. Patch size is set to 8 instead of the
usual 16, for finer spatial granularity (784 tokens instead of 196), with
patch and position embeddings resized from a patch-16 checkpoint rather
than reinitialised from scratch. At inference: sigmoid each token's logit,
reshape into a grid, bilinearly upsample to full resolution, threshold.

## Data

Training pools 8 public breast-ultrasound sources (3,373 images from 3,263
patients). A ninth source, BUS-BRA, is deliberately excluded from training
entirely and used only as the test population — both for in-domain testing
(train and test on BUS-BRA) and for a cross-population test (train on the
other 8 sources, test on BUS-BRA with no BUS-BRA labels ever seen).

## Results

The oracle analysis is the clearest evidence for the core idea — at the
same patch size, continuous labels beat binarised ones by a wide margin,
and finer patches push the ceiling further still:
